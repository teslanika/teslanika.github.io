Player bio

I am a product manager in EdTech who builds with AI every day. I write Claude Code skills, hooks and guardrails that keep agents honest: every claim has a source, nothing goes out without a human review, and nothing gets deleted by accident. I also teach. I wrote a course that takes analysts from zero to shipping AI-assisted code, AI lessons for kids aged 8–10, and Viola, a pixel game for learning Bulgarian.

Harness engineering

  • Mods for Claude Code itself, including my own dog that walks above the prompt.

Security

  • Guardrails for destructive commands: scan, show the list, then act; move to trash, never delete.
  • I audit third-party agent plugins line by line before I install them.
  • Secrets live in one locked file and never in chat, cards or commits.
  • Least privilege for agents: read by default, write only where I said so.

House rules

The rules my agents follow. They are also the rules I teach.

Raw sources stay untouchedNotes and summaries are built from them, never the other way round.
Every claim links to a sourceNo source means it is an assumption, and it says so.
Model output is a draftA person reads it before it counts.
Show contradictionsTwo sources disagree? Both stay on the page.
Nothing goes out by itselfThe agent prepares; a human sends.
Check both directionsIs what is printed true, and is anything important missing?
