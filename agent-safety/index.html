Agent Safety Check

Seven checks of your chat app's settings, so that your protection works outside the model. A rule you only tell the model is a reminder, not a lock.

From the talk at Analyst Days, 2026-11-19. For chat apps (Claude, ChatGPT, others) with connectors to mail, drive, calendar or chat.

Open a new chat in the app you use, paste the prompt, and answer its questions. It walks you through the seven checks one at a time and ends with a table of what is still open. It cannot see your settings: you look, you tell it what you see.

1Blast radius

You cannot protect what you have not named. The worst case decides how strict the rest must be.

What to set
Write, in two or three lines, the worst thing this chat could do with today's connections (send mail as you, delete files, post in a work channel, share a document). If the answer is scary, cut connections first.
One-minute test
Read your two lines aloud. If any line names an action you would not survive at work, go to Least Privilege before anything else.

2Least Privilege

The agent can only misuse access it has. Every connector you do not need is risk with no benefit.

What to set
Turn off connectors the work does not need. Where the app offers it, make a connector read-only or block its write and delete tools. Share one folder, not the whole drive. Never paste passwords, API keys or tokens into a chat or a project file. If the app shows no connectors at all, the state is done with "no connectors".
Where in your app

Claude

  • Customize > Connectors from vendor help, 2026-11-18
  • In a chat: + > Connectors > Manage connectors from vendor help, 2026-11-18
  • Customize > Connectors > [connector] > Tool permissions: set write and delete tools to Blocked for a read-only connector from vendor help, 2026-11-18

ChatGPT

  • Settings > Plugins (older builds: Settings > Apps) > [app] > Disconnect from vendor help, 2026-11-18

Another app

  • look for Settings > Connectors, Apps, Extensions or Integrations. If none exist, the state is done with "no connectors".
One-minute test
List your connectors. Each one left on has a reason you can say in one sentence.

3Approval Gate

An agent that acts without asking will one day act on a misunderstanding. A human click before the action is a lock the model cannot talk its way past.

What to set
Keep "ask before acting" (needs approval) for every connector action that sends, deletes, pays or changes who has access. Never choose "always allow" for those.
Where in your app

Claude

  • Customize > Connectors > [connector] > Tool permissions: Needs approval from vendor help, 2026-11-18
  • New layout: the message-box mode Manual asks before each action; Auto does not from vendor help, 2026-11-18

ChatGPT

  • Plugins directory > [app] > Preferences > Ask permission: Always ask or Any changes from vendor help, 2026-11-18
  • Settings > Security > Advanced security > Lockdown Mode from vendor help, 2026-11-18

Another app

  • look inside each connector's settings for "ask", "approval" or "permissions". If the app never asks before acting, the state is this app cannot do it: then keep only read-only connectors.
One-minute test
Ask the chat to draft and send a test email to yourself. It must stop and ask before sending. If it sends without asking, the gate is open.

4Audit Trail

An agent can report a result it did not achieve: "sent", "saved", "deleted" when nothing happened, or something else happened. A log the model writes itself is not an audit trail, because the same model that got it wrong writes the log.

What to set
Know where the app itself shows each tool call and its raw result (drawn by the app, not written by the model), and where each connected service keeps its own log: sent mail, drive activity, chat history in Slack or Teams. Rule: when the chat says sent, saved or deleted, check it in the service before believing it.
Where in your app

Claude

  • Settings > Privacy > Export data from vendor help, 2026-11-18
  • Enterprise admin: Organization settings > Data and Privacy > Export logs from vendor help, 2026-11-18

ChatGPT

  • Settings > Data controls > Export data from vendor help, 2026-11-18

Another app

  • Gmail: Sent folder; Google Drive: Activity panel (i icon) of the file or folder from vendor help, 2026-11-18
  • Slack and Teams: the channel or chat itself; the message is there or it is not from vendor help, 2026-11-18
  • these are the services' own records, which the model cannot write. Compare them with what the chat said.
One-minute test
Ask the chat to do one action through a connector, then find it in the service's own log and compare with what the chat said.

5Kill Switch

When something goes wrong you need to stop it in seconds, and cutting access in the chat app does not always cut it at the service.

What to set
Know the stop button for a running answer, how to disconnect a connector in the app, and how to revoke the app's access at the service itself (Google, Microsoft, Slack, GitHub account pages).
Where in your app

Claude

  • Customize > Connectors > [connector] > Disconnect from vendor help, 2026-11-18
  • Google: myaccount.google.com/connections > Claude > Delete all connections from vendor help, 2026-11-18

ChatGPT

  • Settings > Plugins > [app] > Disconnect from vendor help, 2026-11-18

Another app

  • Google: myaccount.google.com/connections > [app] > Delete all connections from vendor help, 2026-11-18
  • Microsoft work or school: myapplications.microsoft.com > ... > Manage your application > Revoke permissions from vendor help, 2026-11-18
  • Slack: workspace menu > Tools and settings > Manage apps > Installed apps > [app] > Remove from vendor help, 2026-11-18
  • GitHub: Settings > Applications > Authorized OAuth Apps > Revoke from vendor help, 2026-11-18
  • permissions an admin granted for the whole company cannot be revoked by you on the Microsoft page; ask your admin. Microsoft personal accounts: no official page found, not listed.
One-minute test
Start a long answer and stop it. Then open the revoke page for one connector and find the chat app in the list. You do not have to remove it.

6Lethal Trifecta

Three things together let an attacker steal your data through the agent: untrusted content it reads, private data it can see, and a way to send data out. Term by Simon Willison.

What to set
Never combine all three in one chat. Untrusted content is web search, an inbox, shared documents. Private data is your files, mail, notes. A way out is any connector that can send, post or write somewhere others can read. Keep at most two of three.
Where in your app

Claude

  • Older layout: + > Web search (a checkmark means on) from vendor help, 2026-11-18
  • Team and Enterprise admin: Organization settings > Capabilities > Web search from vendor help, 2026-11-18

ChatGPT

  • Message box > View all tools > Search, or type / then Search from vendor help, 2026-11-18

Another app

  • look for a web search or browsing switch in the message box or in settings.
One-minute test
For your usual chat, name which of the three it has. If it has all three, turn one off (web search is often the easiest) or split the work into two chats.

7Context Amnesia

In a long chat, early instructions fall out of the model's attention or get summarized away. A rule given in the first message is gone by the fiftieth.

What to set
Put standing rules in project instructions or custom instructions, not in the first message of a long chat. Start a new chat for a new task. This is a reminder to the model, not a lock: it makes good behaviour more likely, it does not enforce it.
Where in your app

Claude

  • Settings > Your Claude > Instructions (older layout: Settings > Account > Instructions for Claude) from vendor help, 2026-11-18
  • Settings > Your Claude > Manage next to Your memory (older layout: Settings > Capabilities) from vendor help, 2026-11-18
  • Ghost icon at the top right of a new chat: incognito, not saved to memory from vendor help, 2026-11-18

ChatGPT

  • Settings > Personalization > Custom instructions from vendor help, 2026-11-18
  • Settings > Personalization > Memory > Manage from vendor help, 2026-11-18
  • New chat > Temporary: not saved to memory from vendor help, 2026-11-18

Another app

  • look for custom instructions, personalization, project or gem instructions, and memory.
One-minute test
Open a new chat in the project and ask it to repeat your rules. If it cannot, they are not where you think.

Next level

Use a separate account or browser profile for agent work, so a mistake stays inside it. Keep passwords and keys in a password manager, never in a chat or a project file. On a work account, ask your admin which of these settings the company already decides for you.
